## Getting Started

1. Install the **AdMyChat** extension from the VS Code Marketplace or Open VSX Registry.
2. Open the AdMyChat panel or run `AdMyChat: Sign In in Browser` from the command palette (`Ctrl+Shift+P`).
3. Start coding! Your daily earnings appear in your editor's status bar and update live on [admychat.com/wallet](https://admychat.com/wallet).
